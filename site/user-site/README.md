# Files for the user site

Generated by `./dmse site`. Copy them to the root of the `benjamindehli.github.io`
repository, the user site, and publish it through GitHub Pages.

A `robots.txt` is only honoured at the root of a domain, so the one each plugin site
generates at `/<Repo>/robots.txt` is never read by a crawler. These two files are read:
the `robots.txt` points at the sitemap index, and the index lists the sitemap of every
plugin site, so all of them are discoverable from one URL rather than thirteen manual
submissions in Search Console.

If that repository already has a `robots.txt`, merge the `Sitemap:` line into it rather
than overwriting the file. Re-run `./dmse site` and copy them again whenever a plugin is
added or removed.
