# Files for the user site

Generated by `./dmse site`. The user site is the `benjamindehli.github.io` repository, an
Astro project that publishes from `docs/`, so copy `sitemap-index.xml` and
`llms.txt` into its `public/` folder and let the build carry them to the domain
root.

`llms.txt` is the index an answer engine reads to find the instruments: one entry
per product with a one-line description, and a link to the full markdown manual
each product site publishes at `/<Repo>/llms.txt`. If the user site grows a wider
`llms.txt` of its own, keep the instrument sections and add the rest around them
rather than keeping two competing files.

A `robots.txt` is only honoured at the root of a domain, so the one each plugin site
generates at `/<Repo>/robots.txt` is never read by a crawler. The `benjamindehli.github.io` one is,
and it needs a single line added so the index is found:

    Sitemap: https://benjamindehli.github.io/sitemap-index.xml

That one line makes the sitemap of every plugin site discoverable, including the watch
pages and their video entries, rather than needing thirteen manual submissions in Search
Console. Add it alongside the sitemaps already listed there rather than replacing the
file. Re-run `./dmse site` and copy the index again whenever a plugin is added or
removed.
